Idea Validation

Nov 2026

A repeatable process that tests any business idea against real customer evidence before anything gets built.

Most new products fail on a problem nobody checked, so every idea goes through the same six steps in the same order, whatever the market. Each step ends in a file that the next step reads, and the whole process is packaged as a Claude Code skill with its own scripts, so a new idea starts from the playbook instead of a blank page. The first run, on pet health, found the fatal flaw (clinics hold the records, so an owner's record starts empty and nobody pays for it) and pointed to a fix: charge the businesses that have to check those records.

Quality bar
Each batch of AI tags is compared with my own blind sample and passes at 85%
Ground rules
I contact people myself, under my own name, and nothing is sent without me
Status
First run done; its 30-day test is next
Built with
Claude Code skill, Python, Haiku and Opus subagents, Apple's public review feed

The six steps

  1. Step 1Name the customer, the problem and where they talk
  2. Step 2Kill-shot: who holds the supply, who pays, who already does it
  3. Step 3Mine real complaints, filtered by code and tagged by a small model
  4. Step 4Check the tags blind against my own sample
  5. Step 5Critique it like an investor: pre-mortem, incumbents, unit economics
  6. Step 6A 30-day test under $100, with a pass number and a kill number

On pets, three sourced questions found the fatal flaw for about 80k tokens, after mining had cost about 720k and only hinted at it, so that check now runs before any mining
Themes defined
